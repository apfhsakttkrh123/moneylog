# MoneyLog

대림대학교 전공심화(1년)과정 · 실무프로젝트2 기말프로젝트

MoneyLog는 일상 지출을 기록하고 월별 소비와 예산을 확인하는 개인 소비 관리 웹사이트입니다. 식비, 교통비, 쇼핑 등 항목별로 한 달 동안 얼마를 썼는지 파악하고, 남은 예산을 기준으로 다음 지출을 계획할 수 있습니다.

## 주요 기능

- 날짜, 지출명, 카테고리, 금액과 메모를 담은 지출 내역 등록·수정·삭제
- 월별 총지출과 카테고리별 지출 금액·비중 확인
- 월 예산 설정과 잔여액·사용률·초과 금액 확인
- 지출명과 메모 검색, 카테고리 필터

## 화면 구성

**대시보드형**을 홈으로 확정했습니다. 상단에서 조회할 월을 선택하고 지출을 등록할 수 있습니다. 월간 요약에서는 총지출, 예산, 잔여액을 확인하고, 아래에서 카테고리별 지출과 최근 내역을 봅니다. 전체 내역 화면에서는 지출을 검색하고 수정하거나 삭제할 수 있습니다.

## 개발 환경

- **화면 및 동작** · HTML, CSS, JavaScript
- **데이터 저장** · LocalStorage. 별도 서버 없이 같은 브라우저와 사이트 주소에서 기록을 이어서 확인할 수 있도록 설계했습니다.
- **버전 관리 및 배포** · GitHub, GitHub Pages
